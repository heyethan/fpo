FPO is a codename for a company four of us are building in Mangalore. It has no name yet. That is
what the branding work is for.

**Start here:** [`truth/`](truth/) holds what is true about FPO right now. If you only read one
thing, read [what FPO is](truth/what-fpo-is.md).

## What FPO is, in one line

FPO takes a small, selected group of people in Mangalore and stays with them until they have a
real business or a real career, and it earns from the companies and funds that want access to
them.

## How this repo is organised

```
truth/       what is true now. One answer per question. Current.
archive/     how we got there. Meeting records and exercise results. Frozen.
workshop/    how the branding sessions are run. Not company knowledge.
```

Three rules keep it usable:

1. **A fact lives in one place.** `truth/` states it, `archive/` proves it, nothing is restated.
2. **Every claim says where it was decided**, with a date and a link to the meeting or exercise it
   came from. If you disagree with something, the link tells you which room it was decided in.
3. **`archive/` is never rewritten.** When something changes, `truth/` changes and the archive file
   gets a note saying it was superseded.

## Status of any given claim

Each file in `truth/` carries a `status` in its header.

- `verified` — settled, all four agreed
- `budding` — the current best answer, not locked
- `evergreen` — a living list that will keep changing
- `stale` — known to be out of date

## Who can read what

Each file carries an `audience` field. Everything is `founders` today. As advisors come in, files
marked `advisors` can be shared without reorganising anything. [truth/people.md](truth/people.md)
contains each founder's own account of their record and stays founders-only until each of us says
otherwise.
